# Unreal Engine Blueprint

## Overview  
This project showcases various Unreal Engine Blueprint implementations, including interactive lighting, door mechanics, and character animations. The environment has been enhanced with textures and an improved door design.  

## Features  

### 🏠 **Part 1: Light Toggle System**  
- Created a **room** with a **point light** inside.  
- The light **automatically turns on** when the player enters the room.  

### 🚪 **Part 2: Interactive Elements** 
- Added an **interactive door** that can be opened and closed using the **E key**.  
- Implemented **two wall lights** that can be toggled on and off with the **E key**.  
- Displayed **on-screen interaction text** when the player approaches the **door or wall lights**.  

### 🕺 **Part 3: Character Animation Blueprint** 
- Imported the character model **John**.  
- Implemented **five animations**:  
  - **Idle Breathing**  
  - **Walking**  
  - **Running**  
  - **Idle Jump**  
  - **Running Jump**  
- Created an **Animation Blueprint** for seamless transitions between animations.  

## Additional Improvements 🌟  
- **Enhanced environment textures** for the play area and room.  
- **Improved door design** by adding a **frame**.  

## How to Play  
1. Walk into the room to **turn on the point light**.  
2. Press **E** near the door to **open/close** it.  
3. Press **E** near the wall lights to **toggle them on/off**.  
4. Move around to experience character animations.
